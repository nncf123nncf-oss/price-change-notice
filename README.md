# 価格改定のお知らせセット

100日100プロダクトチャレンジ Day090（2026-11-05）

お店の名前・新しい価格にする日・メニューごとの今の価格と新しい価格（税込）を入れると、次の3つが一緒にできるWebページです。

- 新旧が並んだ価格表の画像（PNG・1080×1350）
- お知らせ文（SNS・LINE向け／店内掲示・お手紙向け）
- A4縦の張り紙（印刷）

## 使い方

`index.html` をブラウザで開きます。「見本を入れる（美容室）」「見本を入れる（飲食店）」で架空のお店の例を入れられます。

## 扱うデータ

- 入力はこの端末のブラウザの中だけで扱い、当サイトには送信しません
- 入力は、この端末のブラウザ（localStorage）に下書きとして残ります
- アクセス解析（Cloudflare Web Analytics）でページの閲覧状況を計測しています
- お知らせ文は決まった言い回しに入力を差し込んだ下書きです。価格や表示が法律に合っているかは判断しません
